# 24navobot — AI Assistant Platform for Telegram & Social Networks

Official repository for the **24navobot** web platform: [https://24navobot.pythonanywhere.com/](https://24navobot.pythonanywhere.com/)

## Overview
**24navobot** allows creators, businesses, and community managers to connect smart AI bots to Telegram (with YouTube, Instagram, Facebook, Threads, TikTok, X, LinkedIn, and VK coming soon). The assistant automatically replies to users in private chats and groups based on your custom rules and knowledge base.

## Key Features
- **Custom Instructions & Persona**: Configure rules up to 4,000 characters, custom greetings, and fallback messages.
- **Knowledge Base**: Upload up to 3,000 characters of factual data (prices, terms, FAQs) for accurate answers on Pro and Business plans.
- **Live Web Search**: Real-time web search integration for up-to-date responses.
- **Multi-Model Support**: Supports OpenRouter free models, OpenAI (`gpt-4o-mini`, `gpt-4.1-mini`, `gpt-5-mini`), and Google (`gemini-2.5-flash`).
- **Built-in Anti-Spam & Security**: Rate limiting (up to 10 messages/minute per user), encrypted bot tokens, and automatic 7-day chat history cleanup.

## Quick Start
1. Sign in with Telegram at [https://24navobot.pythonanywhere.com/](https://24navobot.pythonanywhere.com/).
2. Create a bot via `@BotFather` and paste the API token into your cabinet.
3. Set your instructions and activate the assistant.
